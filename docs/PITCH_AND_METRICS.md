## 2. Структура питч-дека (10 слайдов под Марата Толыбая, Руппеля и Коломейцева)

1. **Титул:** `Commit Guardian` — On-Premise AI AppSec-аудит каждого коммита для финтеха, медтеха и GovTech (без утечки исходного кода в облако).
2. **Боль и пруфы:** реальные утечки ПДн + результаты собственного анонимного опроса жителей и IT-специалистов Казахстана (`X%` сталкивались со спамом/утечками, средний балл доверия `N/5`, `Y%` требуют проверки до релиза без зарубежных облаков).
3. **Почему существующие решения не подходят:**
   - Облачные SAST / AI (Snyk Cloud, GitHub Copilot, ChatGPT) → передают исходники во внешние облака (бан ИБ в банках/госсекторе).
   - Тяжёлые enterprise-комбайны (SonarQube Enterprise / Checkmarx) → месяцы интеграции, сложны и дороги для команд 5–50 разработчиков.
4. **Решение и живое демо:** `git push` → HMAC-верифицированный webhook → SAST + Taint Engine + `.aegis.yml` (кастомные правила на ИИН/ПДн) → локальная модель Ollama (`ALLOW_CLOUD_LLM=false`) → `Security Score` (`A+..F`) + комментарий в PR + алерт и PDF-отчёт в Telegram + `/dashboard` (100% air-gapped).
5. **Техническое преимущество (под Коломейцева, CAIO Sergek):**
   - `allow_cloud_llm = false` на уровне конфигурации;
   - детерминированное ядро + rule-based fallback, если GPU/Ollama недоступна;
   - защита от ложных срабатываний по энтропии Шеннона;
   - SARIF-выгрузка в GitHub Security и SIEM JSON-логи.
6. **Рынок (TAM / SAM / SOM Казахстан + СНГ):** финтех/платёжные провайдеры, GovTech-подрядчики, медтех-платформы и аутсорс-студии (тысячи команд от 5 до 100 разработчиков).
7. **Бизнес-модель и цены:**
   - **Pilot (14 дней):** `0 ₸` — 1–2 репозитория, Docker-развёртывание, PDF + Telegram.
   - **Team On-Premise:** `190 000 ₸ / мес` (~$380) — до 25 разработчиков, `.aegis.yml` политики ПДн, PR-комментарии, SIEM-логи.
   - **Enterprise Air-Gapped:** `от 650 000 ₸ / мес` — изолированный контур, кастомные правила комплаенса и SLA.
8. **Трекшн и текущая готовность:** рабочий монолит (FastAPI + Next.js + Telegram-бот + CLI + Docker), `55+` автотестов в CI, встроенное live-демо, опрос-валидация рынка, победный опыт команды (Decentrathon 6.0 — 1 место по области Жетісу).
9. **Конкуренты и защита (`Why us?`):** фокус на локальный контур + `.aegis.yml` правила под казахстанские ПДн/ИИН + мгновенная обратная связь в Telegram и PR за минуты вместо недель ручного аудита.

## 3. Ответы на жёсткие вопросы (`Live Roast / Pitch Fix Live`)

- **«Почему Snyk / GitHub / Anthropic не сделают то же самое завтра?»**  
  Snyk и GitHub зарабатывают на облачном SaaS и привязаны к GitHub.com. Банкам, платежкам и гос-подрядчикам в Казахстане нужен инструмент, который **гарантированно не шлёт код в облако** (`ALLOW_CLOUD_LLM=false`), понимает локальные паттерны (ИИН, внутренние платёжные шлюзы) через `.aegis.yml`, ставится в Docker в закрытом контуре и интегрируется с Telegram-ботом и GitLab/GitHub за 15 минут.
- **«А если ваша локальная LLM нафантазирует или зависнет?»**  
  Поиск уязвимостей опирается на **детерминированные сканеры** (AST, межфайловый `TaintEngine`, Semgrep, Bandit, энтропия Шеннона и `.aegis.yml`), а локальная LLM только фильтрует шум и формирует русскоязычное заключение — при её отключении система автоматически переключается на rule-based отчёты и патчи без остановки пайплайна.
- **«Кто уже пользуется и где доказательства, что это купят?»**  
  До выступления мы собрали опрос среди IT-специалистов, владельцев проектов и обычных пользователей в КЗ (цифры с формы) + подготовили воспроизводимый 14-дневный Docker Pilot, который разворачивается на тестовом репозитории заказчика за 15 минут без передачи доступа к коду команде Commit Guardian.
