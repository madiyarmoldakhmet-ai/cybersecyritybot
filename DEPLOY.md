# Деплой Aegis

Проект Aegis собран в единый монолит, что делает его деплой максимально простым. 

## Деплой на Railway / Render / Heroku

В корне проекта находится `Dockerfile`, который описывает `multi-stage` сборку:
1. Сначала собирается фронтенд Next.js (компилируется в статику `out`).
2. Затем устанавливаются зависимости Python, копируется статика и запускается FastAPI.

### Требования к окружению

При деплое вам необходимо задать следующие переменные окружения:

- `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота, полученный у @BotFather.
- `OPENROUTER_API_KEY` (опционально) — для работы интеллектуального чата через OpenRouter.
- `PORT` (обычно задается автоматически платформой) — порт, на котором запускается приложение (по умолчанию 8000).

### Инструкция для Railway

1. Создайте новый проект в Railway.
2. Подключите ваш GitHub репозиторий.
3. Railway автоматически обнаружит `Dockerfile` в корне проекта.
4. Перейдите в настройки сервиса, раздел **Variables** и добавьте переменные окружения (как минимум `TELEGRAM_BOT_TOKEN`).
5. Нажмите Deploy.

Ваш проект (фронтенд, бэкенд и Telegram-бот) запустится как один контейнер и будет доступен по публичному домену Railway.

### Локальный запуск через Docker

```bash
docker build -t aegis-monolith .
docker run -p 8000:8000 --env TELEGRAM_BOT_TOKEN=ваш_токен aegis-monolith
```

Фронтенд и API будут доступны по адресу `http://localhost:8000`. Telegram-бот запустится в фоне.
